# Clase 03-09-26

## Ejercicio: Suma promedio

```smalltalk
| n sum prom |.

n:= (UIManager default request: 'Enter a number > 0') asNumber.

sum:= 0.

1 to: n do: [ :i |
	sum:= sum + i
	].

prom:= (sum / n).

Transcript clear.

Transcript show: prom
```

### Ejercicio mostrar frase:

```smalltalk
| frase |.

frase:= UIManager default request: 'Ingrese una frase: '.

Transcript clear.

1 to: frase size do: [ :c |
	Transcript show: (frase at: c); cr.
	
	 ].
```
