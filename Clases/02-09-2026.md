## Ejercicio de clase.

### a) Sumar dos números ingresados por teclado y al resultado de esa suma calcularle todos los múltiplos y divisores. 
```smalltalk
| a b c i j top |.

a:= (UIManager default request: 'Enter the firts number') asNumber.
b:= (UIManager default request: 'Enter the second number') asNumber.

c:= (a + b).

Transcript show: 'The result of the addition is: ', c asString; cr.

i:= 1.

[i <= c] whileTrue: [  
	((c \\ i) = 0) ifTrue: [ 
		Transcript show: 'The number ', i asString, ' is a divisor of ', c asString; cr.
		 ].
	i:= i + 1
	]. 

top:= c raisedTo: 3.
j:= (c+c).

[ j <= top ] whileTrue: [ 
	Transcript show: 'The number ', j asString, ' is a multiple of ', c asString; cr.
	j:= j + c
	 ]

```
